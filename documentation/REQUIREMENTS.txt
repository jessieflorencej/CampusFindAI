# CAMPUS LOST & FOUND — SMART AI-POWERED COLLEGE LOST & FOUND PLATFORM

Build a complete, creative, modern, secure, and fully usable **Campus Lost & Found Management System** exclusively for colleges and universities.

The application should allow students and staff to report lost items, report found items, search for possible matches, claim belongings through an intensive verification process, communicate through an AI-powered chatbot, receive notifications, and allow administrators to review and manage the entire lost-and-found workflow.

This should NOT look like a simple college CRUD project.

It should look and behave like a real campus product that could actually be deployed and used by a university.

---

# PROJECT NAME

Use a creative project name such as:

**CampusFind AI**

Tagline:

**Lost on Campus. Found with Intelligence.**

Alternative names:

* FindMyCampus
* CampusRecover AI
* UniFind
* LostLink Campus
* CampusTrace AI

Use **CampusFind AI** as the default project name.

---

# PROJECT OBJECTIVE

CampusFind AI is an intelligent lost-and-found platform designed specifically for colleges.

Students and staff can:

* Report lost belongings
* Report items they have found
* Upload images
* Search items
* Ask an AI assistant
* Receive possible matches
* Claim found items
* Complete ownership verification
* Track claim status
* Communicate securely
* Receive notifications when possible matches appear

Administrators can:

* Review reports
* Verify suspicious posts
* Approve/reject ownership claims
* Monitor misuse
* Manage users
* Manage lost/found inventory
* Review AI-generated matches
* Close successfully returned items
* View analytics

The application should strongly focus on:

**Security, ownership verification, privacy, AI assistance, and real campus usability.**
